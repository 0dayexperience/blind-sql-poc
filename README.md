# Blind SQL Injection – Proof of Concept

Демонстрация техники Boolean-based Blind SQL Injection с бинарным поиском по ASCII.
Код предназначен исключительно для образовательных целей и тестирования
на системах, где у вас есть письменное разрешение.

## Как это работает

1. **Подтверждение уязвимости.** Проверяется разница в ответе сервера на
   `AND 1=1` (истина) и `AND 1=2` (ложь).
2. **Бинарный поиск.** Для каждого символа данных алфавит сужается вдвое,
   что требует не более 7 запросов на символ вместо ~50 при линейном переборе.
3. **Извлечение данных.** Скрипт демонстрирует извлечение первых трёх символов
   пароля администратора из таблицы `users`.

## Ограничения

- Работает только для демонстрационных стендов (например, DVWA, bWAPP).
- НЕ предназначен для атак на реальные системы без авторизации.
- Требует корректного маркера `SUCCESS_MARKER`, уникального для каждого приложения.

## Защита

Для предотвращения подобных атак рекомендуется:
- Использовать параметризованные запросы (prepared statements).
- Настроить WAF с правилами для обнаружения SQL-инъекций.
- Проводить регулярный аудит кода и пентесты.
